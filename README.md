# AI_HEALTHCARE_ASSISTANT

An AI-powered Healthcare Assistant that predicts the most likely disease based on user symptoms using Machine Learning. 
The application also estimates disease severity, provides medical precautions, explains the predicted disease, shows top predictions and generates a downloadable medical report.

##  Features

- Disease prediction using Machine Learning
- Ensemble model (Random Forest + XGBoost)
- NLP-based symptom extraction and validation
- Explainable AI using SHAP
- Severity level prediction
- Existing medical condition support
- Disease description
- Recommended precautions
- Top 5 disease predictions with probabilities
- PDF medical report generation
- Interactive Streamlit web application

##  Technologies Used

- Python
- Streamlit
- Scikit-learn
- XGBoost
- SHAP
- spaCy
- Pandas
- NumPy
- Joblib
- FPDF
